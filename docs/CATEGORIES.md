# 분류 체계 — 1음절 가안 평가와 수정안

상태: **수정안 v1 (사용자 확정 전)**. 코드는 `src/data/categories.ts`. 분류별 작성 가이드라인은 사용자가 나중에 준다 — [확인 필요].

## 1. 원안 (사용자 이미지)

맛 · 멋 · 쉼 · 득 · 봄(돌봄) · 삶 · 놀 · 봄(풍경) · 책 · 길 · 잠 · 팁 — 12칸.

## 2. 평가

| 문제 | 해당 칸 | 왜 문제인가 |
|---|---|---|
| **같은 글자 두 번** | 봄(돌봄) · 봄(풍경) | 필터·URL·범례에서 구분할 수 없다. 원안 메모대로 하나는 바꿔야 한다. |
| **분류가 아니라 속성** | 득(실속·할인) | '저렴한 약국'은 몸, '할인 식당'은 맛이다. 득은 **어느 분류에나 붙는 성질**이라 주 분류로 두면 한 장소가 늘 두 칸에 걸린다. |
| **분류가 아니라 글의 종류** | 팁(주차·화장실·꿀팁) | 주차장·화장실은 '장소'라 삶에, 꿀팁은 장소에 딸린 정보라 태그에 맞다. |
| **경계가 겹침** | 쉼의 '미술관' ↔ 멋(취향)·책(사색) | 미술관은 쉼보다 멋(보는 감각)에 가깝다. 쉼은 카페·찻집처럼 '앉아서 머무는 곳'으로 좁힌다. |
| | 득 ↔ 삶, 팁 ↔ 삶 | 세탁·수선·편의와 주차·화장실·할인 정보는 사용자 입장에서 모두 '생활'이다. |
| | 봄(풍경) ↔ 길 | 꽃길·전망 명소는 대부분 걸어서 닿는 곳이다. 계절은 장소보다 **시기**의 성질이다. |
| **단어로 어색함** | 놀 | '놀'은 단독으로 쓰지 않는 말(놀다의 어간). 소리 내어 읽으면 뜻이 흐려진다. |
| | 득 | 뜻은 통하지만 '이득'의 반쪽이라 딱딱하다(속성으로 옮기면 해결). |
| **필터로 너무 많음** | 12칸 전체 | 지도 위 칩 12개는 모바일 한 줄(390px)에 4–5개만 보인다. 사람이 한눈에 구분하는 색도 8–9개가 한계다. |
| **표기** | 전체 | 로마자(mat, swim, mom, jam, sam)는 영어 단어로 오독된다. URL·DB 키와 영문 라벨은 **영어 단어**를 쓴다. |

## 3. 수정안 v1 — 9칸 + 속성 3개

| 음절 | 영문(키) | 뜻 | 예시 | 원안에서 |
|---|---|---|---|---|
| 맛 | Eat (`eat`) | 먹는 즐거움 | 식당 · 디저트 · 빵 | 그대로 |
| 쉼 | Rest (`rest`) | 머물러 쉬는 곳 | 카페 · 찻집 · 쉼터 | 미술관을 멋으로 |
| 멋 | Style (`style`) | 취향과 감각 | 편집숍 · 건축 · 갤러리 | 미술관·갤러리 흡수 |
| 책 | Read (`read`) | 지식과 사색 | 서점 · 도서관 · 북카페 | 그대로 |
| 길 | Walk (`walk`) | 걷고 바라보기 | 산책로 · 골목 · 전망 · 꽃길 | 봄(풍경) 흡수 |
| 잠 | Stay (`stay`) | 머무는 공간 | 숙소 · 스테이 | 그대로 |
| **흥** | Play (`play`) | 즐거운 경험 | 체험 · 공연 · 놀이 | 놀 → 흥 |
| **몸** | Care (`care`) | 건강과 돌봄 | 병원 · 의원 · 약국 | 봄(돌봄) → 몸 |
| 삶 | Living (`life`) | 생활의 발견 | 세탁 · 수선 · 주차 · 화장실 | 득·팁의 장소 흡수 |

**속성 태그** (분류와 겹쳐 붙음, 지도에서는 별도 토글)

| 태그 | 원안 | 쓰임 |
|---|---|---|
| 실속 | 득 | 할인·저렴함. 어느 분류에도 붙는다 |
| 꿀팁 | 팁 | 그 장소에 대해 알아두면 좋은 정보가 있는 글 |
| 계절 | 봄(풍경) | 봄·여름·가을·겨울 중 고름. "봄에 가면 좋은 길" |

'몸' 대신 원안 메모의 '의'(醫)도 가능하지만, 한자어 단음절이라 뜻이 바로 오지 않는다. '뷰'는 외래어라 다른 칸과 결이 다르다. '흥' 대신 '놀이'(2음절)나 '판'도 후보다 — [확인 필요].

### 더 줄이는 안 (8칸)

책을 멋에 합치면(서점은 취향의 공간) 8칸이 된다. 색 구분과 모바일 칩 줄은 더 편해지지만, 책을 따로 모으고 싶다면 9칸을 유지한다. **추천은 9칸.**

## 4. 규칙

1. **주 분류 1개** (필수) — 마커 색과 음절을 정한다. 기준: "이곳에 가는 가장 큰 이유".
2. **보조 분류 최대 2개** — 필터에는 걸리지만 마커 모양은 주 분류를 따른다. 예: 서점 겸 카페 = 책(주) + 쉼(보조).
3. **속성 태그** — 실속·꿀팁·계절. 개수 제한 없음.
4. 분류를 바꾸거나 추가하는 것은 **관리자 권한**이다(docs/AUTH.md).

## 5. 색과 지도

- 9색은 색상환을 고르게 나눴고, **흰 글자/연한 바탕 대비 4.5:1 이상**(WCAG AA)이 되도록 진하기를 맞췄다.
- 색만으로 구분하지 않는다. 마커 안에는 항상 음절 글자가 들어간다(색약 대응).
- 카드 배경(tint)은 원안 이미지의 파스텔 카드 느낌을 이어받는다. 시안 B의 필터 칩에서 쓴다.
